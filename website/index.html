ARCHITECTURE

Token already there. One direct call. Same numbers.

Claude Usage Monitor doesn't have its own login, server, or cloud account. It connects directly from your Windows desktop to Anthropic.

01

Token, already there

Claude Code stores your OAuth credential securely in Windows Credential Manager under Claude Code-credentials. We read that token automatically.

02

One direct call

The app makes a direct HTTPS request to GET /api/oauth/usage directly to api.anthropic.com. No proxy, no third-party middleman.

03

Same numbers as /usage

Returns your exact 5-hour session and weekly utilization figures — identical to running the CLI's internal /usage command.

04

System Tray + Dashboard

Live dynamic tray icon with status ring indicator. Hover for instant numbers or click for the full monochrome editorial dashboard.

SECURITY & PRIVACY

Nothing leaves your Windows machine except Anthropic's API.

🔒

Local-First Storage

Historical usage snapshots and preferences remain on your local machine inside %APPDATA%\ClaudeUsageMonitor\history.db. No external database or cloud synchronization.

🛡️

Zero Telemetry & Analytics

No Google Analytics, no Mixpanel, no crash reporting servers, no tracking beacons. Your usage data is strictly your own.

🔑

Redacted Log Files

OAuth tokens, bearer strings, and API keys are automatically redacted from application logs before writing to disk.

⚡

Direct Anthropic Connection

The only network requests made by this application are direct HTTPS queries to api.anthropic.com using standard TLS encryption.

CAPABILITIES

Built like a real product. Craft in every detail.

Dynamic System Tray Icon

Dynamic 32x32/64x64 monochrome icon generated via Pillow. Accent dot shifts from Green to Orange to Red as limits approach.

5-Hour & Weekly Windows

Tracks both rapid 5-hour session caps and long-term weekly utilization percentages with relative reset countdowns.

Usage Velocity Analytics

Calculates your usage velocity (% per hour), recent trend direction, today's peak usage, and estimated time remaining before limit hit.

SQLite 30-Day History

Stores 15-minute history samples locally. View interactive monochrome SVG line graphs across 24-hour, 7-day, and 30-day timeframes.

Windows Toast Notifications

Configurable notifications at 80% warning and 90% critical thresholds with built-in cooldown debouncing to prevent spam.

Editorial Monochrome UI

Lightweight native pywebview interface with Dark & Light theme modes, high-contrast typography, and smooth transitions.
